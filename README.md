# STORM RETROARCH 1.1.0

> Ультра-быстрый флагманский фронтенд и эмулятор Libretro с автоматической докачкой ядер, нулевой задержкой ввода и поддержкой 30+ игровых платформ в дизайне STORM AURORA FLUID.

---

### Ключевые возможности

- **Умное распознавание 30+ платформ**: автоматическое определение консоли по расширению ROM-файла или структуре архива (`NES`, `SNES`, `Genesis`, `PlayStation 1`, `N64`, `GBA`, `NDS`, `3DS`, `PSP`, `Dreamcast`, `Saturn`, `Arcade/FBNeo`, `DOS`, `PC Engine`, `Atari` и др.).
- **Фоновая авто-докачка ядер Libretro**: автоматическая загрузка нужного ядра с официального Buildbot Libretro при первом запуске игры или выборе в менеджере ядер, с отображением скорости и прогресса.
- **Турбо-профиль и нулевая задержка**: поддержка графических бэкендов `Vulkan`, `Direct3D 11/12` и `OpenGL`, синхронизация `VRR / G-Sync / FreeSync (120–240 Гц)`, предиктивные кадры (`Preemptive Frames / Run-Ahead`) и `WASAPI Low-Latency Audio`.
- **Полноэкранный режим OZONE**: запуск RetroArch в чистом полноэкранном интерфейсе Ozone в 1 клик.
- **Повсеместный умный Drag-and-Drop**: поддержка перетаскивания файлов и папок по всей площади окна с автоматическим обходом ограничений UIPI (`ChangeWindowMessageFilterEx`).
- **9 динамических тем, 13 акцентов и 10 шрифтов**: мгновенное переключение цветовых палитр (`MIDNIGHT`, `NIGHT`, `DARK`, `DAY`, `FANTASY`, `CYBERPUNK`, `SYNTHWAVE`, `BLOOD MOON`, `ARCTIC`) и акцентных оттенков.
- **11 языков с автоопределением языка ОС**: русский, английский, немецкий, французский, китайский, корейский, японский, испанский, итальянский, португальский и хинди.
- **Интеграция с системным треем**: фоновый режим Close-to-Tray со строгим контекстным меню без лишних декораторов.
- **Автоматическая система обновлений**: проверка доступности новых сборок через GitHub Releases и зеркало STORM GAMES WORLD с возможностью гибкого отключения в настройках.
